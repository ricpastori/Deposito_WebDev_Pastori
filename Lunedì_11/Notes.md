* **IDE** ->  Isola e centralizza gli strumenti di sviluppo, evitando ridondanze negli errori e impedendo che vengano registrati sul PC (es. nel registro di sistema).
* I **sistemi distribuiti** scompongono le applicazioni su più macchine per collaborazione e tolleranza ai guasti, mentre i **sistemi scalabili** hanno la capacità di gestire carichi crescenti aumentando le risorse (verticalmente o orizzontalmente)
* **Javascript Everywhere** -> Metodologia organizzativa che prevede uno stack full javascript (sia client e server)
* **Node.js** -> Non solo runtime ma anche server “framework”
* **React** -> Archetipo components -> più scalabile
* **Angular** -> Archetipo codebase -> distribuibile
* **PHP** -> Linguaggio OOP
* **Javascript/Typescript** -> Linguaggio multiparadigma
* **JSP** -> Stack Java, Spring Boot, PostgreSQL (organizzazione Java EveryWhere)
* Oltre a **LAMP** (utilizzato di più) c’è anche **WAMP**. Quest’ultimo utilizza Windows al posto di Linux
