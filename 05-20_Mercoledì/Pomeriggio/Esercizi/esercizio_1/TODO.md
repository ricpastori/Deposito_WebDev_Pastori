# J.H.C - Esercizio
Realizzare una pagina web composta da:
- [ ] un titolo
- [ ] un div con del testo
- [ ] tre bottoni
- [ ] una lista vuota (ul)
- [ ] un input di testo

La pagina deve essere divisa in 3 file:
- [ ] index.html
- [ ] style.css
- [ ] script.js

## Obiettivi DOM - Con JavaScript bisogna:
- [ ] selezionare gli elementi tramite getElementById()
- [ ] leggere il valore scritto nell’input
- [ ] creare nuovi elementi li
- [ ] aggiungere gli elementi alla lista
- [ ] modificare il testo del titolo
- [ ] eliminare l’ultimo elemento della lista

## Obiettivi CSS - Con JavaScript bisogna anche modificare dinamicamente lo stile degli elementi usando .style.
Bisogna:
- [ ] cambiare il colore del titolo
- [ ] modificare il colore di sfondo del div
- [ ] aumentare la dimensione del testo
- [ ] aggiungere un bordo al div
- [ ] nascondere e mostrare un elemento

## Extra difficile - Aggiungere anche:
- [ ] cambio stile al passaggio del mouse (mouseover)
- [ ] contatore automatico degli elementi presenti nella lista
- [ ] cambio colore casuale del titolo
- [ ] bottone “Reset” che riporta tutti gli stili iniziali
- [ ] eliminazione di un elemento cliccandoci sopra
